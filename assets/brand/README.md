# Shaft symbol mark

`shaft-mark.svg` is the geometry source. Other SVG and PNG files are usage variants or previews.

`shaft-readme-hero.svg` is the repository README banner.

## Usage

- Default: `shaft-mark.svg` (`#111318`)
- Strict black: `shaft-mark-black.svg`
- Dark backgrounds: `shaft-mark-white.svg`
- Optional accent: `shaft-mark-indigo.svg` (`#4F46C8`)
- Minimum display size: `16 px`
- Minimum external clear space: `4` units on the `24 × 24` construction grid

Keep the vertical counter transparent. Do not rotate, outline, round, skew, or add effects.

Transparent PNG exports are available at `16`, `24`, `32`, and `64` px under `png/`.
